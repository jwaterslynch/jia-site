# JIA Public Site

This repository hosts the public GitHub Pages site for JIA.

Purpose:
- provide a shareable public-facing site without exposing the private product repository
- keep the interactive manuscript review app and API-backed pipeline private

Expected publish target:
- `https://jwaterslynch.github.io/jia-site/`

The site is pure static HTML/CSS/JS so it can deploy directly through GitHub Pages.
